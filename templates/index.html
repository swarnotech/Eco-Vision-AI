ABOUT THE PROJECT

Technology Meets Sustainability.

EcoVision AI is a smart waste management project designed to make waste classification easier and more efficient. It uses a machine learning model trained on waste images to recognize different types of garbage.

By helping users identify waste categories, the system aims to encourage proper waste segregation, recycling awareness and environmentally responsible habits.
